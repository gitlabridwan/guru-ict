Kebijakan Privasi

Informasi ZuperVerse dengan frontend GitHub Pages dan backend mandiri milik pengelola.

1. Data pada perangkat

Nama karakter, penampilan, progres permainan, pengaturan dan soal buatan pengguna disimpan pada penyimpanan browser di perangkat yang dipakai. Data ini tidak otomatis berpindah ke perangkat lain. Menghapus data situs pada browser dapat menghapus progres dan soal.

2. Fitur online

Setelah backend dipasang, akun guru (nama, email, nomor kontak, sekolah), kelas, identitas murid, materi yang dibuka, jawaban dan nilai tersimpan pada database pengelola di Cloudflare D1. Kata sandi disimpan sebagai hash, bukan teks asli. Token sesi juga disimpan sebagai hash. Frontend dan backend ini tidak memakai database atau akun situs asal. Pengelola bertanggung jawab menetapkan kontak, masa simpan, akses data dan prosedur penghapusan sesuai penggunaan sekolahnya.

3. Materi dan tautan pihak ketiga

Video YouTube, tautan Google Drive, layanan AI dan tautan WhatsApp yang dibuka pengguna mengikuti kebijakan masing-masing penyedia. Materi eksternal memerlukan internet. Font, ikon dan aset panduan dalam paket ini tersedia secara lokal.

4. Cache offline

Service worker menyimpan salinan berkas situs agar halaman dapat dibuka kembali saat offline. Cache dan penyimpanan situs dapat dihapus melalui pengaturan browser.

5. Hosting

Penyedia hosting dapat memproses informasi teknis permintaan, seperti alamat IP dan jenis browser, sesuai kebijakannya. Jangan memasukkan data sensitif ke soal atau repository publik.

6. Hubungi pengelola

Kontak pengelola dapat diisi melalui konfigurasi situs. Hubungi pengelola situs.
