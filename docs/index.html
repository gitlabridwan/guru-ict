🗺️ Pilih duniamu

ZuperVerse terdiri dari banyak dunia. Paket soal dari guru bisa dimainkan di dunia mana pun, jadi murid bebas memilih tempat petualangannya.

Belajar terasa seperti main game

Setiap mata pelajaran berubah menjadi gedung di sebuah kota yang hidup. Murid bergerak bebas, mengumpulkan hadiah, dan menjawab soal untuk naik level.

🏙️

Kota 3D yang Hidup

Rumah warga, jalan raya, mobil, angkot, bus sekolah, air mancur, lampu jalan, danau, dan lapangan sepak bola.

🏫

Gedung Mapel

Setiap mapel menjadi satu gedung. Masuk pintunya untuk kuis dengan nyawa, waktu, combo, dan pembahasan.

🎯

Misi & Level

Misi utama dan misi harian dengan XP, level, dan koin. Progres tersimpan di perangkat murid.

👕

Lemari Gaya

Seragam SD, SMP, SMA, pramuka, batik, topi, toga, kacamata, ransel, sampai jubah pahlawan.

💬

Bantu Warga

Warga kota punya pertanyaan. Bantu mereka menjawab untuk mendapat koin tambahan.

📺

Ruang Materi

Setiap gedung bisa berisi video YouTube, link, file Google Drive, gambar, atau ringkasan teks dari guru untuk dipelajari sebelum kuis.

📖

Buku Ilmu

Buku tersebar di seluruh kota. Kumpulkan semuanya untuk menyelesaikan misi kolektor.

Skema pemakaian untuk semua guru

Satu aplikasi bisa dipakai banyak guru sekaligus. Setiap guru menyusun paket soal sendiri sesuai mapel dan kelasnya, lalu membagikannya ke murid. Isi kota langsung menyesuaikan: satu mapel menjadi satu gedung, maksimal 12 gedung per paket.

1

Susun soal

Isi soal dan materi (video YouTube, link, teks) lewat Editor Visual, tempel JSON, atau minta AI membuatkannya dengan Prompt AI.

➜
2

Simpan & bagikan

Buat Link Paket lalu kirim lewat WhatsApp, atau bagikan file .json ke guru lain.

➜
3

Murid bermain

Murid membuka link. Paket otomatis termuat dan gedung-gedung mapel muncul di kota.

➜
4

Pantau hasil

Dengan Kelas Online, nilai dan analisis soal langsung masuk ke dashboard guru. Tanpa server, murid mengirim kartu hasil lewat WhatsApp.

TAHAP 1 • SUDAH BISA

Tanpa server

  • Guru menyusun paket di Mode Guru.
  • Dibagikan sebagai link (#p=...) atau file .json.
  • Setiap guru bebas punya paket per mapel atau kelas.
  • Materi video, link, dan teks di setiap gedung.
  • Hasil dikirim murid lewat WhatsApp.
TAHAP 2 • SUDAH BISA (dengan server)

Kelas Online & Dashboard

  • Guru membuat kelas dan mendapat kode, misalnya K7M2QX.
  • Murid masuk dengan nama panggilan dan nomor absen.
  • Nilai, jawaban per soal, dan materi yang dibuka tercatat otomatis, juga saat sinyal putus-sambung.
  • Dashboard: rekap nilai, ketuntasan KKTP, analisis butir soal, rekomendasi tindak lanjut, dan unduh Excel.
TAHAP 3 • PENGEMBANGAN

Main Bersama (real-time)

  • Murid satu kelas berada di kota yang sama.
  • Pesan cepat dan emote yang aman untuk anak.
  • Mode Lomba: semua murid menjawab soal yang sama serentak.
  • Papan peringkat langsung.

Format paket soal (JSON)

{ "judul": "Matematika Kelas 5 - Pecahan", "guru": "Nama Guru", "jenjang": "SD Kelas 5", "mapel": [ { "nama": "Pecahan", "warna": "#ef4444", "waktu": 30, "jumlah": 10, "materi": [ {"judul": "Video: Mengenal Pecahan", "jenis": "video", "url": "https://youtu.be/..."}, {"judul": "Ringkasan", "jenis": "teks", "isi": "Pecahan adalah ..."} ], "wajibMateri": false, "soal": [ { "q": "1/2 + 1/4 = ...", "opsi": ["3/4", "2/6", "1/6", "2/4"], "jawab": 0, "bahas": "1/2 = 2/4, jadi 2/4 + 1/4 = 3/4", "gambar": "(opsional) link gambar" } ] } ] }
