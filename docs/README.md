# Website ZuperVerse

Folder ini adalah sumber GitHub Pages. Pilih branch `main`, folder `/docs` pada Settings → Pages. Panduan lengkap ada pada `PANDUAN_LANGKAH_DEMI_LANGKAH.md` di tingkat utama paket/repository.

- `config.js`: alamat backend dan WebSocket milik Anda.
- `setup.html`: pemeriksaan koneksi.
- `admin.html`: panel pengelola backend mandiri.
- `assets/game.js`: kode permainan dan editor.

Backend berada pada folder `backend/` di luar folder publik ini. Jangan menyimpan secret admin di sini.
